# HUWARI

오늘 입을 옷 조합이 잘 어울리는지,  
온라인에서 새로 산 옷이 기존 옷장과 맞는지 고민될 때 빠르게 확인할 수 있는 코디 분석 웹 서비스다.

의류 이미지를 올리거나 웹캠으로 지금 입고 있는 옷을 찍으면  
AI가 색·재질·패턴·스타일을 분석해 조화 점수(0~100)와 피드백 문장을 함께 제공한다.

단순히 점수만 주는 게 아니라 어떤 부분이 잘 어울리고 어디가 어색한지를  
말풍선 형태로 설명해 주며, 마음에 드는 코디는 히스토리에 저장해 이전 조합과 비교할 수 있다.

아이템을 하나씩 바꿔가며 전체 밸런스가 어떻게 달라지는지 실험해 볼 수 있어,  
옷 구매 전 가장 잘 어울리는 조합을 미리 점검하는 데 유용하다.

## 개발 과정

| 단계 | 내용 |
|------|------|
| 1단계: 데이터 수집 및 전처리 | 패션 데이터셋 조사 및 선정, 라벨 정제 및 데이터 전처리 |
| 2단계: 모델 설계 및 학습 | 속성 분류 및 조화 판단 모델 설계, 모델 학습 및 파인튜닝 |
| 3단계: 백엔드 구현 | FastAPI 기반 REST API 설계 및 구현, 모델 서빙 및 추론 파이프라인 연결 |
| 4단계: 프론트엔드 구현 | React 기반 UI 설계 및 구현, 이미지 업로드·코디 캔버스·히스토리 기능 구현 |
| 5단계: 웹캠 기능 구현 | 웹캠 실시간 의류 감지 파이프라인 구현, 실시간 조화 분석 및 캡처 기능 구현 |
